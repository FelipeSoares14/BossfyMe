# BOSSFYME

App de produtividade com um chefe caricato, o **Dr. Alberto**: você assume tarefas e ele cobra a execução, uma por vez.

## Versões

| Pasta | O que é |
|---|---|
| `v1-original/` | Primeiro protótipo, com identidade própria. Congelada. |
| `v2-bossfy/` | Lógica da v1 com o visual do design system BossFy. |
| `v3-flow/` | Segue o flow v3: relógio da tarefa, vereditos, central de desculpas. |

Detalhes e links publicados no [VERSOES.md](VERSOES.md).

Os wireframes estão nos arquivos `BOSSFYME Wireframes*.dc.html`.

## Como abrir

Abra o `index.html` no navegador. Ele leva às três versões.
